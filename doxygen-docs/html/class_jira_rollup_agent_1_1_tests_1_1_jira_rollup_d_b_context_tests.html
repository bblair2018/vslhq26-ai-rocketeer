Detailed Description

Unit tests for JiraRollupDBContext.OnModelCreating: the collation annotation, every foreign key's configured DeleteBehavior (see CLAUDE.md's FK relationship table for the documented reasoning behind each), and one live save+requery round trip proving the resulting schema actually works end to end. Backed by a real SQLite in-memory database - not EF Core's InMemory provider, which can't translate UnitOfWork.DeleteAllRowsAsync's raw SQL and doesn't meaningfully enforce FK/cascade configuration.
