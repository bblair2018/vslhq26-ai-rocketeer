Detailed Description

Unit tests for ReportGeneratorService: the pure HTML/text-formatting helpers (Encode, ApplyBold, FormatSummaryText), the repo-root resolution helper, the HTML-assembly methods, and Run()'s skip/failure/success paths. The full success path is exercised via the Run(string? repoRootOverride)/WriteReportAsync(html, repoRootOverride) overloads pointed at an isolated temp directory, rather than the parameterless Run() - which walks up from the test binary's own directory looking for the real repo's .slnx marker file and would overwrite the real report/rollup-report.html if exercised end-to-end.
