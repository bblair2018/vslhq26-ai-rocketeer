Detailed Description

Unit tests for JiraHierarchyLoaderServiceType: the mock-DTO-to-entity mapping helpers, and the Run() skip/success paths. The success path reads this test project's own small fixture MockData/jira-hierarchy.json/team-roster.json (copied to the test binary's output directory), not the real 5100-line hierarchy under src/JiraRollupAgent/MockData/.
