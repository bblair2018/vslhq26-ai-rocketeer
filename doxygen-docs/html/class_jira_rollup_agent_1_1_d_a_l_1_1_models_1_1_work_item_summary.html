Detailed Description

The generated summary for a single WorkItem (Story/Bug/Task/Spike/Subtask/StoryBug) - Type A (leaf) or Type B (Story, rolling up its Subtask/StoryBug summaries), never role-weighted. Exactly one row per WorkItem: overwritten fresh on every SummarizationService run, not a history table. Never printed directly in the report - consumed as input by the Story (if this is a Subtask/StoryBug) or Epic (if this is a Story/Bug/Task/Spike) summary above it.
