Detailed Description

The "Report" stage: renders report/rollup-report.html - Initiatives ordered by Initiative.PriorityRank, each showing its Business Summary with its Epics nested underneath showing their Engineering Summaries. Self-disables after a successful run - see DisableReportGenerationFlagAsync.
