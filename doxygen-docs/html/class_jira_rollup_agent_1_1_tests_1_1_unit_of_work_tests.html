Detailed Description

Unit tests for UnitOfWork, backed by a real SQLite in-memory database: named and generic repository caching, UnitOfWork.DeleteAllRowsAsync/UnitOfWork.DeleteAllSummariesAsync's raw SQL (which EF Core's InMemory provider can't translate), UnitOfWork.SaveAsync/UnitOfWork.CompleteAsync, and UnitOfWork.Dispose.
