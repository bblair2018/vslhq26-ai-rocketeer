Detailed Description

The "Extract" stage: deserializes MockData/jira-hierarchy.json + team-roster.json and loads them into VSLiveJiraRollup, standing in for a real Jira ingestion pipeline. Self-disables after a successful run - see DisableHierarchyLoadFlagAsync.
