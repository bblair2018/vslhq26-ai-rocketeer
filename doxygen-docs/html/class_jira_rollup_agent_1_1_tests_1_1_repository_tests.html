Detailed Description

Unit tests for the generic Repository<T>, exercised against TeamMember (a simple entity with no foreign key dependencies), backed by a real SQLite in-memory database - these methods are thin wrappers around a real EF Core DbSet<TEntity> that mocking IRepository<T> elsewhere would trivially bypass.
