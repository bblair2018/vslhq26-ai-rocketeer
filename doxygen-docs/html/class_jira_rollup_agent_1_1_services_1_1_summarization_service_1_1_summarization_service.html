Detailed Description

The "Summarize" stage: generates and persists a summary for every Initiative/Epic/WorkItem via Azure OpenAI, walking the hierarchy bottom-up (see BuildSummaryChainAsync) so each level's summary is built from its own comments plus its children's already-generated summaries. Self-disables after a successful run - see DisableSummarizationFlagAsync.
