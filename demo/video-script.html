What It Does 0:30 – 1:05

[VISUAL: record visual-2-architecture.html — the Jira Hierarchy → Azure OpenAI → Rollup Report pipeline]
"This is the Jira Rollup Agent. It takes a full Jira hierarchy — Initiatives, Epics, Stories, Bugs, Tasks — and sends it through Azure OpenAI in a chain: every ticket gets summarized from its own comments, then rolled up into its Epic, then rolled up into its Initiative. The output is a single HTML report, sorted by business priority.

For this demo, that hierarchy comes from a realistic mocked dataset rather than a live Jira pull — the ingestion side is a separate, already-built pipeline, and its real output can drop in without changing any of this summarization logic."

Under the Hood 2:35 – 3:05

[VISUAL: record visual-3-under-the-hood.html — the recursive rule + the three prompt types]
"Under the hood, this isn't one giant prompt. It's a recursive chain built on Azure OpenAI through Azure AI Foundry: leaf tickets summarize first, Stories roll up their Subtasks, Epics roll up their Stories into an Engineering Summary, and Initiatives roll up their Epics into a Business Summary. Each level only ever reads the level below it — so the model never loses track of who said what."
